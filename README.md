# LSTM Financial Market Prediction

This project explores the use of **Long Short-Term Memory (LSTM)** neural networks for predicting financial market trends based on historical data. The financial data is sourced from **Yahoo Finance** and used to train models that aim to forecast future price movements.

The goal is to experiment with deep learning techniques to improve time series forecasting accuracy in the context of stock market data.
